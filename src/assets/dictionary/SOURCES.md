# Dictionary Sources

This directory contains source files for the game dictionary.
The `dictionary.txt` file is generated by merging these sources using `scripts/merge-dictionaries.ts`.

## Sources

| File | Description | URL |
|Data Source|Description|URL|
|---|---|---|
| `source-lexique383.txt` | Lexique383 (~142k words) | [Lexique.org](http://www.lexique.org/) |
| `source-kaikki.txt` | Kaikki (Wiktionnaire) (~398k words) | [Kaikki.org](https://kaikki.org/dictionary/French/index.html) |
| `source-ods8.txt` | ODS8 Scrabble Dictionary (~411k words) | [Thecoolsim/French-Scrabble-ODS8](https://github.com/Thecoolsim/French-Scrabble-ODS8) |
| `source-gutenberg.txt` | Liste de mots français Gutenberg (~336k words) | [OpenLexicon](https://github.com/chrplr/openlexicon/blob/master/datasets-info/Liste-de-mots-francais-Gutenberg/README-liste-francais-Gutenberg.md) |
| `source-taknok.txt` | French Wordlist (~22k words) | [Taknok/French-Wordlist](https://github.com/Taknok/French-Wordlist) |
| `source-words.txt` | JSON Array of French Words (~336k words) | [words/an-array-of-french-words](https://github.com/words/an-array-of-french-words) |
| `source-hbenbel.txt` | Full French Dictionary (CSV) | [hbenbel/French-Dictionary](https://github.com/hbenbel/French-Dictionary) |

## Maintenance

To update the dictionary:

1. Run `pnpm dictionary:download` to fetch all sources (saved in `src/assets/dictionary/temp/`).
2. Run `pnpm dictionary:merge` to merge and normalize them into `dictionary.txt`.
3. Run `pnpm dictionary:generate` to create the optimized Bloom Filter.
